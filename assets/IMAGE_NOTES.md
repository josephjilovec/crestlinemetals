# Crestline representative imagery

The homepage uses the existing repository's Pexels industrial-process photograph, image 7739856. Source: https://www.pexels.com/photo/7739856/ and the existing images.pexels.com asset URL.

The 800px and 1600px WebP files are delivery variants requested from that same image service. They preserve the photograph and are not AI-generated facility imagery. The image does not depict an identified Crestline facility and is labeled representative beside its display.

Other existing page photographs remain representative context with an explicit notice. Their requested widths are reduced to suit display needs. No equipment, facility ownership, operating capacity, certification, or production result is established by these images.

The traceability traveler is original HTML and contains placeholder fields. It is not an actual mill certificate or inspection record.
